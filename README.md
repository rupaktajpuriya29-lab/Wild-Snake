# 🐍 Wild Snake

A browser-based Snake game built as a single HTML file. No installs, no downloads: open it and play.

**▶️ Play it here:** https://rupaktajpuriya29-lab.github.io/Wild-Snake/

---

## 💡 Core Idea

Wild Snake takes the classic Snake game and makes it my own. The goal is simple: **grow as long as you can without hitting yourself or the walls.**

## 🎮 How to Play

- Move the snake with the **arrow keys** (or **WASD**). 
- Eat the food to grow longer and score points.
- Don't crash into the walls or your own tail.
- Try to beat your high score.

## ✨ Features

- Playable directly in the browser
- Score tracking
- Background music

## 🛠️ Built With

- HTML
- CSS
- JavaScript

All in one file: `wild_snake.html`.

## 🚀 Run It Locally

1. Download `wild_snake.html`.
2. Double-click it to open in your browser.

That's it.
